=========================================================
 CÀI MCP CHO CLAUDE DESKTOP — LÀM ĐÚNG 6 BƯỚC DƯỚI ĐÂY
=========================================================

Giải nén nguyên thư mục MCP_cai_dat này ra một chỗ cố định,
ví dụ  D:\MAYA_TOOLS\MCP_cai_dat\  — về sau đừng di chuyển nó,
vì Claude nhớ đường dẫn tuyệt đối.

Máy cần Python 3.10 trở lên (khuyên 3.12).

  >> CHƯA CÓ PYTHON? BẤM ĐÚP cai_python.bat, nó lo hết. <<
  Máy đã có sẵn rồi thì nó báo "khong can cai gi them" rồi thoát,
  chạy nhầm cũng không hỏng gì.

Python này KHÔNG liên quan đến Python bên trong Maya. Maya có Python
riêng, không cài đè được và cũng không cần.


BƯỚC 1 — Sửa MỘT dòng trong cai_dat_mcp.bat
       (chưa có Python thì bấm đúp cai_python.bat trước)
-------------------------------------------
Chuột phải file cai_dat_mcp.bat > Edit. Sửa dòng:

    set MAYA_MCP=D:\MAYA_TOOLS\MayaMCP-main

cho đúng chỗ bạn để MayaMCP (thư mục CHỨA src\maya_mcp_server.py).
Chưa có MayaMCP thì kệ nó — bộ cài sẽ tự bỏ qua và chỉ cài artspec.

artspec nằm sẵn cạnh file .bat, KHÔNG cần khai báo gì thêm.


BƯỚC 2 — Chạy thử khô (chưa ghi gì cả)
--------------------------------------
Mở CMD trong thư mục này (gõ  cmd  vào thanh địa chỉ của File Explorer)
rồi chạy:

    cai_dat_mcp.bat --dry-run

Nó in ra đoạn JSON và dòng "(--dry-run: chưa ghi gì cả)". Xem qua thấy
đường dẫn đúng thì sang bước 3.


BƯỚC 3 — Cài thật
-----------------
BẤM ĐÚP vào cai_dat_mcp.bat.

Lần đầu chạy mất vài phút (tạo môi trường ảo, tải thư viện). Xong phải
thấy các dòng:

    ✓  MayaMCP: server chạy thử OK
    ✓  artspec: server chạy thử OK
    ✓  đã ghi 2 server vào cấu hình

Cấu hình cũ của Claude được sao lưu tự động, không mất gì.


BƯỚC 4 — THOÁT HẲN Claude Desktop rồi mở lại
--------------------------------------------
Bấm X đóng cửa sổ KHÔNG đủ. Claude chỉ đọc cấu hình lúc khởi động.

    Windows: chuột phải icon ở khay hệ thống (góc phải taskbar) > Quit
    Mac:     Cmd + Q

Rồi mở lại Claude.


BƯỚC 5 — Mở cổng lệnh trong Maya  (chỉ cần nếu dùng MayaMCP)
------------------------------------------------------------
Mở Maya > Windows > General Editors > Script Editor.

  >> PHẢI DÁN VÀO TAB "Python", KHÔNG PHẢI TAB "MEL". <<
  Hàng tab nằm ở NỬA DƯỚI cửa sổ Script Editor. Không thấy tab Python thì
  chuột phải vào hàng tab > New Tab > chọn Python.
  Dán nhầm tab MEL sẽ báo:  // Error: Line 1.2: Syntax error

Dán toàn bộ nội dung file mo_cong_maya.py vào, bấm Ctrl+Enter.
Thấy dòng "Da mo cong 50007" là được.

Lười thì dán đúng 2 dòng này cũng đủ:

    from maya import cmds
    cmds.commandPort(name=":50007", sourceType="mel")

(chữ sourceType="mel" KHÔNG liên quan đến tab bạn đang dán — nó là kiểu
lệnh MayaMCP gửi qua cổng. Vẫn phải dán vào tab Python.)

Lần đầu Claude gọi sang, Maya hiện hộp thoại bảo mật > bấm "Allow All".

  >> Hai việc này phải làm lại MỖI PHIÊN MAYA. Cổng không tự mở lại. <<


BƯỚC 6 — Kiểm tra
-----------------
Trong Claude gõ:  bạn có tool nào?
Phải liệt kê ra tool của MayaMCP và artspec.

Rồi thử bài test chống bịa (BẮT BUỘC làm một lần):
hỏi một điều techspec KHÔNG hề quy định, ví dụ
"số vertex tối đa cho decal là bao nhiêu?"
Trả lời ĐÚNG phải là "techspec không có quy định này".
Nếu nó bịa ra một con số thì báo lại ngay, đừng dùng tiếp.

------------

Chép nguyên đoạn chữ cửa sổ đen in ra (nhất là dòng "LỖI:" hoặc "⚠")
gửi lại cho tôi.
